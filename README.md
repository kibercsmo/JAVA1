# Метод MaxNum

## Что делает?

Выводит максимальное число из списка... Все...

## Versions 

### Vesion 0.1

Добавлен метод, выводящий наибольшее число *(Не обязательно целое)* из переданного списка

### Vesion 0.2

Добавлен консольный ввод чисел, сначала колличество, затем сами числа

### Vesion 0.3

Зачем-то теперь выводит наименьшее из чисел
